# 红豆文献联动 for 思源笔记

把 [红豆](https://www.inoteexpress.com) 文献库接进思源：**正文写引用、文末自动长参考文献表**，换一个 CSL 样式全篇重排；也能按分类浏览文献、一键建阅读笔记、把 PDF 批注带颜色语义搬进文档，反过来把思源里写好的笔记、标签、分类写回红豆。

v0.7 起支持**完整双向联动**：在红豆里右键文献「发送到思源」，思源这边自动落笔——不用切窗口复制粘贴。

> 社区插件，与红豆官方、思源官方均无隶属关系。全程通过红豆自带的本地 MCP 服务通信，不读写红豆数据库文件。

---

## 安装

### 思源侧（本插件）

1. 思源 → 设置 → 集市 → 已下载 → 找到「红豆文献联动」启用；
2. 或手动把 `package.zip` 解压到 `工作空间/data/plugins/hongdou-for-siyuan/`；
3. 首次启用会有引导，确认红豆已启动（默认 `127.0.0.1:18500`）。

### 红豆侧（反向推送用，可选）

反向推送需要在红豆里装一个配套的 Zotero 格式插件：

1. 下载 `hongdou-siyuan-bridge-0.3.0.xpi`；
2. 红豆 → 工具 → 插件中心 → **从文件安装** → 选这个 xpi；
3. 重启红豆；
4. 红豆菜单「工具 → 红豆 ↔ 思源：显示配对码」，记下 6 位数字；
5. 思源 → 设置 → 红豆文献联动 → 「配对」→ 输入 6 位码。

配对完成后，在红豆里右键任意文献 →「发送到思源」，2–3 秒内在思源光标处自动插入引用。

## 功能

### 一、引用体系（核心）

| 功能 | 说明 |
| --- | --- |
| 正文引用 | 插入 `[1]` 或 `(Zhang et al., 2024)`，形态跟随所选 CSL 样式，也可手动指定 |
| 文末参考文献表 | 按 CSL 引擎渲染，自动编号、自动排序、样式内联斜体 |
| 换样式全篇重排 | 一篇文档里所有引用和文末表一次性重排 |
| 叙述式引用 | `Zhang et al. (2024)` 单独开关，或右键单条切换 |
| 数字式上标 | `[1]` 可渲染成上标 |
| 引用合并 | 多处引用合成 `[1,3,5]`，连续区间压成 `[1–3]` |
| 编辑引用 | 右键引用 → 取消勾选移除某条、或从红豆当前选中追加 |
| 撤销 | `⌥⌘Z` 恢复上一次重排前的正文与文末表（每篇独立 20 步） |
| 快照兜底 | 红豆断连时，正文引用和文末表仍能靠快照保住 |
| 断链检查 | 扫本篇引用，标出红豆里已删除/改 key 的，可一键移除 |

### 二、写作增强（v0.7 新增）

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| **引用悬停预览** | — | 鼠标停在正文引用上，浮出完整参考文献条目 + 「在红豆打开」「打开 PDF」两个独立按钮 |
| **复制参考文献（富文本）** | `⇧⌘B` | 一次复制整个文末表，粘到 Word / 邮件保留缩进与 DOI 链接 |
| **本篇引用清单** | `⇧⌘L` | 列出本篇所有引用，可逐条打开红豆 / 打开 PDF / 定位回正文 |
| **导出 Word** | `⇧⌘W` | 先刷新引用再导出 .docx，正文引用与文末参考文献都已就位 |
| **谁引用了这篇** | — | 反向索引：列出工作空间里引用了这条文献的所有文档 |
| **引用图谱索引** | — | 生成「文献引用索引」文档，每篇文献下列出引用它的文档（块链接），思源关系图自动连成网 |
| **每篇独立样式** | — | 这篇用 GB/T 7714、那篇用 APA，互不干扰 |

### 三、文献管理

| 功能 | 说明 |
| --- | --- |
| 搜索插入 | 按标题/作者/年份/期刊/标签搜索，支持多选批量插入 |
| 分类浏览 | 左侧分类树，逐级下钻 |
| 文献卡片 / 完整信息 | 一键插入结构化文献信息块 |
| 阅读笔记 | 按模板新建笔记，模板支持按文献类型分段（`[journalArticle]` / `[book]`） |
| PDF 批注导入 | 带页码回链，**高亮颜色转成语义标签**：🔑 核心 / ⚠️ 争议 / ✅ 结论 / ❓ 待查 / 💡 想法 / 🧩 关联 / 📌 方法 / · 备注 |
| 笔记导入 / 写回 | 把红豆笔记读进思源，也能把思源笔记写回红豆条目 |
| 标签 / 分类写回 | 把思源里打的标签、归的分类同步回红豆 |
| 多格式导出 | BibTeX / RIS / CSL-JSON / Markdown 表 / LaTeX·Typst 引用命令 |

### 四、双向联动（v0.7 新增）

| 功能 | 说明 |
| --- | --- |
| 红豆右键「发送到思源」 | 红豆端插件把选中文献推入队列 |
| 思源自动落笔 | 每 2–30 秒轮询一次，有新推送自动插到光标处，顶栏显示红点 |
| 6 位配对码鉴权 | 本机 `127.0.0.1` 通信，一次性配对，令牌持久化 |
| 打开 PDF 走红豆阅读器 | 取 PDF 附件 key → `hongdou://open-pdf/...`，批注能同步；也可切系统阅读器 |

## 设置项

设置 → 红豆文献联动：

- **红豆接口地址**：默认 `http://127.0.0.1:18500/mcp`
- **正文引用形态**：自动 / 作者-年份 / 数字式
- **参考文献样式**：跟随红豆当前样式或指定某个 CSL
- **PDF 用什么打开**：红豆阅读器（推荐）/ 系统阅读器
- **Word 导出目录**：留空用桌面
- **红豆 → 思源 反向推送**：配对按钮、状态刷新、桥接端口（默认 18501）、自动插入开关、轮询间隔

## 常见问题

**Q：文末表没更新？**
执行「刷新本篇引用与参考文献」（`⇧⌘R`）。插入引用后插件也会自动重排（可关）。

**Q：红豆断连了还能看引用吗？**
能。快照存在文档属性里，正文和文末表都保得住；恢复连接后重排一次即可。

**Q：点「打开 PDF」没反应？**
先确认这篇在红豆里有**本地 PDF 文件**（在线链接附件不行）。插件会用附件 key 唤起红豆阅读器；红豆没响应时自动退回系统默认阅读器。

**Q：红豆里右键没有「发送到思源」？**
说明红豆端 bridge 插件没装或没启用。按上面「红豆侧」步骤装一次，并确认红豆重启过。

**Q：配对码输对了还报错？**
配对码 10 分钟过期，且**重新点一次菜单会生成新码**。以弹窗里最新那个为准。

## 隐私

- 所有通信只在本机 `127.0.0.1`，不联网、不上传任何数据；
- 只读取红豆通过 MCP / bridge 暴露的数据，**不直接读写红豆数据库文件**；
- 配对令牌存在本机思源插件设置里。
